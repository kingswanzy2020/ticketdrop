How a request reaches a service, port by port

Pick a request and follow the dot. The response comes back along the same path.

  • Each pod also listens on the admin port 9090 for health checks and metrics. No route points at it, so it can't be reached from outside.
  • The public port appears once, at 8088. From Traefik inward, every service uses 8080, and each has its own IP, so they don't clash.
  • Your Gateway listener uses 8000, the port inside the Traefik pod, not 8088.
